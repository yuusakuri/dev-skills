# Overlapping skills

Curating five collections leaves some phases with more than one option. Where that
happens the router lists both.

| Overlap | Difference |
|---|---|
| `superpowers:test-driven-development` vs `tdd-guide` | The former is stricter about watching the test fail; the latter is a gentler walkthrough. |
| `superpowers:requesting-code-review` vs `pr-review-expert` | Asking for a review well, versus performing a structured reviewing pass. |
| `incident-commander` vs `incident-response` | Outage versus security event. Different playbooks, not substitutes. |
| `senior-security` vs `security-guidance` | Auditing a change, versus guidance while writing it. |

Two skills that match the same request are a routing hazard: the agent picks between
them unpredictably. Once a team settles on one, disable the other rather than leaving
the choice to chance.
